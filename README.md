# हिन्दू — सनातन ज्ञान डिजिटल पुस्तकालय

नेपाली भाषामा हिन्दू धर्म, वेद, उपनिषद्, पुराण, इतिहास, मन्त्र, श्लोक, तिथि/मिति र कथाहरूलाई खोज्न र पढ्न सजिलो बनाउने मोबाइल-फर्स्ट वेब एप।

## मुख्य भागहरू
- 🕉️ वेद, उपनिषद् र शास्त्र
- 📖 भगवद्गीता — अध्याय, श्लोक, अर्थ
- ⚔️ महाभारत र रामायणका कथा
- 📚 पुराण र देवी-देवतासम्बन्धी ज्ञान
- 📿 मन्त्र, स्तोत्र र श्लोक
- 🪔 तिथि, मिति, पर्व तथा दैनिक धार्मिक जानकारी
- 💬 गीता तथा पुराणबाट दैनिक/शफल उद्धरण
- 🔎 नेपालीमा शक्तिशाली खोज
- 🤖 GitHub Actions द्वारा नियमित सामग्री अद्यावधिक

## सामग्री अद्यावधिक प्रणाली
`.github/workflows/update-content.yml` ले नियमित रूपमा विश्वसनीय सार्वजनिक स्रोतहरूबाट मेटाडाटा/सामग्री सङ्कलन गर्छ। Wikipedia/Wikimedia API प्राथमिक स्रोत हो। Google Custom Search API credentials उपलब्ध भएमा खोज परिणामहरू पनि सङ्कलन गरिन्छ।

> महत्वपूर्ण: धार्मिक मूलग्रन्थलाई अन्धाधुन्ध web-scrape गरेर overwrite गर्नु हुँदैन। मूल श्लोक/मन्त्रका लागि प्रमाणित स्रोत र स्पष्ट source attribution राखिन्छ। व्याख्या/अर्थलाई स्रोतसहित छुट्टै field मा राखिन्छ।
