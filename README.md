# हिन्दू — सनातन ज्ञान डिजिटल पुस्तकालय

नेपाली भाषामा हिन्दू धर्मका ग्रन्थ, देवता, मन्त्र, श्लोक, कथा, दर्शन, तिथि र पञ्चाङ्गलाई खोज्न र पढ्न मिल्ने मोबाइल-first knowledge platform।

## मुख्य भागहरू
- 📜 चार वेद र वेदाङ्ग
- 🪷 भगवद्गीता — १८ अध्याय/श्लोक संरचना
- ⚔️ महाभारत र रामायण
- 📚 पुराण र उपनिषद्
- 🪔 भगवान् — देवी, देवता, अवतार र सम्बन्धित कथा
- 📿 मन्त्र, स्तोत्र, जप र श्लोक
- 🗓️ तिथि, मिति, नक्षत्र, पर्व र पञ्चाङ्ग
- 📖 नेपाली हिन्दू कथा तथा ज्ञान विश्वकोश
- 🔎 एउटै unified search
- 📱 mobile knowledge navigation
- 🔄 GitHub Actions आधारित content ingestion/validation

## डेटा दर्शन
मूल धार्मिक पाठ, आधुनिक व्याख्या र web-discovered information लाई एउटै कुरा मानिँदैन। प्रत्येक corpus मा source/provenance राख्ने लक्ष्य छ। उपलब्ध open datasets मध्ये DharmicData ले गीता, महाभारत, वाल्मीकि रामायण, ऋग्वेद, यजुर्वेद र अथर्ववेदलाई structured JSON मा उपलब्ध गराउँछ; यसको README अनुसार dataset ODbL अन्तर्गत छ। https://github.com/bhavykhatri/DharmicData

## लक्ष्य
यो repository लाई क्रमशः:

`ग्रन्थ → अध्याय/पर्व/काण्ड → श्लोक → नेपाली अर्थ → कथा → पात्र → देवता → सम्बन्धित ग्रन्थ → स्रोत`

भएको interconnected knowledge graph मा विस्तार गर्ने हो।
