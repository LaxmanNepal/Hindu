# हिन्दू कथा corpus

यस directory मा कथा/घटना metadata र verified source references राखिन्छन्। सम्पूर्ण महाभारत/रामायण/पुराणलाई एउटा विशाल, fabricated नेपाली summary JSON मा मिसाइँदैन। Primary texts लाई छुट्टै corpus मा राखेर प्रत्येक कथालाई सम्बन्धित ग्रन्थ, पर्व/काण्ड/अध्याय र पात्रसँग जोडिनेछ।

स्रोत विस्तारका लागि DharmicData जस्ता structured open-source corpora प्रयोग गर्न सकिन्छ; त्यस repository मा Mahabharata, Valmiki Ramayana, Bhagavad Gita, Rigveda, Yajurveda र Atharvaveda datasets छन्।
