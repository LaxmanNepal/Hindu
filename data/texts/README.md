# मूल शास्त्र डेटा

यो फोल्डरमा बाह्य खुला स्रोतबाट प्राप्त शास्त्रीय पाठ राखिन्छ। प्रत्येक dataset सँग स्रोत र license metadata राख्नुपर्छ।

## प्राथमिक स्रोत
- Bhagavad Gita: `https://github.com/ChiragMirani/gita-quotes` — upstream ले 700/701 verses र public-domain translation बताउँछ।
- Vedic/Hindu corpus reference: `https://github.com/bhavykhatri/DharmicData` — ODbL-1.0; Rigveda, Yajurveda, Atharvaveda, Mahabharata, Valmiki Ramayana आदि।
- Bhagavad Gita API/reference: `https://github.com/vedicscriptures/vedicscriptures.github.io`

**नियम:** अनुवाद, टीका वा आधुनिक व्याख्या स्वतः 'free' मानिँदैन। मूल Sanskrit पाठ, सार्वजनिक-डोमेन अनुवाद र छुट्टै license भएका सामग्रीलाई अलग metadata सहित राखिनेछ।
